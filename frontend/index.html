01 · Analyze

Read a developer's work

Pulls every public repository, aggregates languages and commit history, scores the profile, then asks a model what it all adds up to.

First run takes 10–40 seconds — it is fetching and analysing every repo. Results are cached, so a re-run is instant.

Same analytics, run twice, aligned on every axis: language mix, repository quality, contribution consistency, and the composite score.

03 · Repo chat

Ask a codebase how it works

Point it at any public repository. Every answer cites the exact lines it came from — click a citation to read the source it used.

Accepts a full URL, an SSH remote, or the owner/repo shorthand.

04 · Job match

Match a candidate to a role

Reads the job description, the resume and the public GitHub profile, then scores the fit with a fixed weighted formula — the model extracts and explains, but every percentage is computed in code and shown with its working.
